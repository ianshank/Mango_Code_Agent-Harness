# DEC-019: The triplicated `digest()` helper across the three control-plane scripts is confirmed intentional (e

## Context

Recorded as a governance decision on the historical pipe log.

## Decision

A tech-debt audit flagged `digest(path) -> hashlib.sha256(path.read_bytes()).hexdigest()` as byte-identical triplicated code across `harness/control-plane/verify_repository.py`, `publish_policy_artifact.py`, and `regenerate_bundle_digests.py`. Confirmed intentional, not an oversight to dedupe: every control-plane script deliberately imports zero symbols from `harness.shared` (`harness/docs/ROOT_OF_TRUST.md`'s mandate that control-plane verifiers must not trust the governed project's own copy of anything an agent in that project could have modified). Deduplicating via a shared `harness.shared` helper would reintroduce exactly the dependency this design excludes; a control-plane-local shared helper would still be a fourth file to keep in sync and buys little at 2 lines each. Left triplicated by design; recorded here so a future audit does not re-flag it as undiscovered debt
