# DEC-070: Per-directory instruction files are AGENTS.md plus a one-line CLAUDE.md import, and their claims are gated

## Context

Two `Agent.md` files existed, in `harness/node/` and `harness/api_server/`. The
name was this repository's own: no external coding agent reads it, and Claude
Code does not load it either. Only `.mango/agents/nemotron-reasoner.md` gave it
force, through a "Persona Topology" instruction telling the reasoner to read one
if it found one.

Three facts decided the replacement.

1. **`AGENTS.md` is the cross-tool standard.** Codex, Copilot, Cursor, Gemini
   CLI and others read it. This repository already ships
   `harness/.github/copilot-instructions.md`, so the reach is not hypothetical.
2. **Claude Code reads `AGENTS.md` only where no `CLAUDE.md` sits at or above
   it** (v2.1.277, 2026-09-18). This repository has one at its root, so a bare
   `AGENTS.md` anywhere in the tree would be inert for the agent it is written
   for. The setting that would load both files is user or managed scope and is
   explicitly ignored in project settings, so it cannot be committed here.
3. **Prose without a gate drifts.** The 2026 standards audit (M26) found
   `harness/node/Agent.md` claiming React/Vite/WebSocket scope over a stack
   whose manifest declares none of them. That finding produced the
   `**Scope:**` check in `test_documentation_claims.py`, which held exactly one
   file.

A fourth fact set expectations rather than design. A factorial study over 1,650
Claude Code sessions (arXiv 2605.10039) found file size, instruction position
and single-versus-nested architecture produced no detectable effect on
instruction adherence. So this change is not justified as making agents obey
more. It is justified as a local map for humans and external tools, and as
documentation whose claims cannot silently become false.

## Decision

Each directory in a derived required set carries an `AGENTS.md` and, beside it,
a `CLAUDE.md` whose entire body is `@AGENTS.md`. The companion is what makes the
document load in Claude Code; a symlink would do the same and was rejected,
because symlinks need `core.symlinks` on Windows checkouts and this repository
carries Windows portability regressions and a scan waiver (DEC-061).

**The required set is derived, never transcribed.** It is every directory
holding at least `agents_doc.min_source_files` first-party sources, minus
`agents_doc.waived_directories`, plus `agents_doc.additional_directories` for
boundaries that are document-worthy but source-light. A hand-typed list passes
forever while the tree grows around it, which is the defect the gate exists to
prevent. A waiver must carry at least `agents_doc.min_waiver_reason_chars` of
reason, so an exemption states why rather than merely existing.

Every claim is checked by `harness/shared/agents_doc.py` in `make ci`: paths on
the `**Scope:**` line and in the `## Key files` table must exist, the companion
body must be exactly the import, `**Reviewed:**` must parse, the file must stay
within `agents_doc.max_lines`, and each mermaid diagram must open with a known
keyword, balance its quotes and brackets, and stay under the node cap.
Thresholds come from the `agents_doc` block of `governance-policy.json` under
the precedence `explicit argument > environment > policy > built-in default`.

Four boundaries are deliberate:

- **No document under `.mango/agents/` or any `harness/*/agents/`.** Those
  `*.md` namespaces *are* the persona set, and five assertions hold them to an
  exact membership. Widening those globs to admit a document would weaken five
  real gates to accommodate prose. Both directories already have a `README.md`;
  the parent document points at it.
- **No document under `docs/`.** Its root refuses loose files, `docs/reports/`
  is a closed index keyed off `harness/README.md`, and every
  `docs/specs/**/*.md` is under the spec contract. `.claude/rules/` path-scoped
  rules cover `docs/specs/` and `docs/decisions/` instead.
- **Technology names on a scope line are not checked here.** `harness/node`
  says `vitest` and `pnpm` truthfully; this module has no manifest to resolve
  them against, and the Node-specific check in `test_documentation_claims.py`
  does. At least one path claim is still required, or the line is unfalsifiable.
- **Staleness does not block a pull request.** A time-based gate over
  twenty-five files would turn `make ci` red for changes that touch none of
  them. A missing or unparseable `**Reviewed:**` line blocks; an old date is
  reported by the weekly drift workflow, the same posture skills already have.

`scope_names` and the `**Scope:**` pattern move into
`harness/shared/agents_doc.py` and are imported back by
`test_documentation_claims.py`. Two copies of one regex is the shim-versus-copy
drift `check_dedup` exists to refuse.

## Consequences

- `harness/node/Agent.md` and `harness/api_server/Agent.md` are renamed with
  `git mv`. The three live references move with them:
  `.mango/agents/nemotron-reasoner.md`, `harness/shared/agent_prompts.py` and
  `test_documentation_claims.py`. The first two are protected paths, so this
  change needs `ALLOW_GITHUB_CHANGES=1`, the `infra-reviewed` label and an
  attestation table. Historical references in `docs/reports/` and
  `docs/specs/2026-standards-remediation-plan.md` are left as written: an audit
  describing a past state should not be retconned.
- Five of the documents land in protected directories
  (`harness/shared/{governance,orchestrator,langgraph}`, `.mango/{skills,hooks}`),
  which is where an agent most needs the local rules and therefore worth the
  attestation rather than an exemption.
- A new source directory now fails `make ci` until it carries a document or a
  justified waiver. That is the intended cost: the alternative is a list that
  silently stops covering the tree.
- `agents_doc.min_documented_directories` is a ratchet in the shape of
  `gates.dedup_min_scripts`. Raise it as the tree grows; never lower it so a
  shrinking population passes.
- An adopter policy that predates the `agents_doc` block keeps working, taking
  the module's built-in defaults rather than raising — the DEC-043 hazard, and
  the reason `gate_floors` carries the same guard.
- Deferred: the `README.md` layout tree still describes the same files these
  documents describe. It stays canonical for now, and
  `agents_doc.max_key_files` caps each document's table so it summarises rather
  than becoming a second copy. Reconciling the two is follow-up work.
