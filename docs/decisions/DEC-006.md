# DEC-006: The guard canonicalises its payload envelope across `tool_input` and `args` and denies a JSON object

## Context

Recorded as a governance decision on the historical pipe log.

## Decision

The guard canonicalises its payload envelope across `tool_input` and `args`, and denies a JSON object carrying neither with exit 2. The orchestrator sent `args.command` while the guard read `tool_input.command`, so every command it submitted was evaluated as the empty string and allowed. Accepting both shapes converts the historical payload from a silent allow into an evaluated command for any adopter still emitting it; non-JSON input keeps its existing leg, because denying every unmodelled payload shape would block tool calls this guard does not model
