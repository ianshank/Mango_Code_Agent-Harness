# DEC-053: `harness/shared/langgraph/` is parked under `harness/shared/experimental/langgraph/` with PEP 562 sh

## Context

LangGraph park; sunset release id TBD (NS-31 / R-SR-5 / R-SR-27; Memo 1 option B; audit M3).

`harness/shared/langgraph/` remains scaffolding after DEC-052's fail-closed conclusive grading on `main` @ `2441547` (PR #88) -- 5/10 nodes stubs, `shadow_planner_node` always 0.0 divergence, recursion/concurrency limits loaded and unused, `checkpointer=None`, and the only production-adjacent caller is experimental (audit M3; review record "Four in-or-out memos"). Further Phase-5 product wiring (reviewer edges, `interrupt()`, LATS end-to-end, HITL in-graph) would deepen a half-done stack that already costs an optional extra, coverage carve-outs, deselection env, and protected-path attestation on every PR

Options considered: (A) promote LangGraph to the live runtime -- apply limits, checkpointer, interrupts, and replace the sequential loop -- rejected until a dedicated revival spec exists and R-CQ-12's default-less `GraphPolicy` is in scope; (B) park under `harness/shared/experimental/langgraph/` with PEP 562 shims and a named sunset -- chosen (Memo 1 option B; R-SR-27); (C) delete outright -- rejected because tests, the `langgraph` extra, and INV-LG-* still document a recoverable experiment and DEC-027 already established the experimental parking pattern for `autonomous_healing` / `lats_optimizer`

Migration order: Phase E implements this as three PRs per Memo 1 after the four NS-31 DECs exist and after NS-2's credential rotation; plan step order is JVM (R-SR-26) → LangGraph park (R-SR-27) → openspec fold (R-SR-28) → mirroring collapse (R-SR-29)

R-SR-5 / AC-5 (this entry + GOVERNANCE_SKILL restatement); R-SR-27 / AC-27 (`DeprecationWarning` on old import; `test_deprecation_shims.py -k langgraph`; `make test-langgraph` from new path); C-SR-4 shim window; DEC-027 parking precedent; DEC-052 fail-closed graph posture preserved under experimental

## Decision

move `harness/shared/langgraph/` to `harness/shared/experimental/langgraph/`; leave PEP 562 shims at the old import paths that re-export public names and emit `DeprecationWarning` naming the new path (AC-27); keep modules tested and coverage-measured from the new path (`make test-langgraph`); do not wire the graph onto the live orchestrator path. Sunset: Memo 1 -- "first minor release after the floor moves" (plan open question 4); the DEC's concrete release id is filled when R-SR-23's shipping release is named (provisional: first minor after the release that lands `requires-python >=3.10`)

## Consequences

INV-15 stays false / LATS off; HITL interrupts and LATS e2e remain parked with this decision (NEXT_STEPS §4); R-CQ-12 stays Phase F only if LangGraph is revived after sunset (R-SR-30); NS-9's import-swallow fix moves with the park PRs rather than landing alone on the old path; DEC-052's fail-closed graph posture is preserved under experimental
