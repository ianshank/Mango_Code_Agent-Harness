# DEC-039: Seven operational defaults accepted as true constants, and the constant inventory made complete

## Context

Recorded as a governance decision on the historical pipe log.

## Decision

Seven operational defaults are accepted as true constants, and the inventory that was supposed to hold them is made complete. `test_constant_triage.py`'s table calls itself the inventory, but every assertion ran in one direction: each listed row was checked for a valid policy or decision link, and nothing checked that every constant which exists is listed. The stated rule -- "a new constant needs a row here" -- therefore had no enforcement, and the way to defeat the inventory was simply not to write the row. Seven had: `agent_prompts.TASK_LOG_PREVIEW_CHARS`, `debug_dump.DUMP_DIR_MODE` and `debug_dump.MIN_ENV_CREDENTIAL_LENGTH`, `meta_tools.DEFAULT_LOCK_TIMEOUT_S`, `meta_tools.DEFAULT_LOCK_POLL_S` and `meta_tools.MIN_LOCK_POLL_S`, and `tool_dispatch.DEFAULT_HYPOTHESIS_CONFIDENCE`. This is the same unbounded-scope failure DEC-032 found in `check_per_file` and DEC-038 found in the attestation table: a gate that judges the set it was handed without asking whether that set is the set that exists. `TestTheInventoryIsComplete` discovers module-level numeric constants from the source with `ast` (parsed, not imported, so the gate does not run the import side effects of the modules it judges) across `harness/shared`, `harness/api_server` and `harness/control-plane`, and requires each to be triaged or to carry an `EXCLUDED` entry stating why it is a fact rather than a limit; exclusions must name a reason, must still be discovered (a stale one is standing permission for a future constant of that name), and must not outnumber the triaged rows. Discovery is numeric-only on purpose -- the shape of an operational limit is a number, and demanding a decision for every string identifier would bury the real rows until the table stopped being read, which is how an inventory dies of over-collection. The seven are true constants, each for a reason of its own rather than by category. `meta_tools`' three are client-local resilience defaults for the advisory file lock on the meta-tool store, the same category DEC-025 accepts: `MIN_LOCK_POLL_S` is a floor that stops a zero or negative caller interval becoming a busy-spin, so it is a safety bound rather than a tunable, and both the timeout and poll interval are already caller-overridable parameters whose defaults matter only when no caller expressed a preference -- a governance threshold would be a threshold no operator has cause to set. `debug_dump.DUMP_DIR_MODE` is 0o700 because a dump directory holds prompts and tool output and the previous code took the default `0o777 & ~umask`, leaving that history world-readable on a shared host; owner-only is a security posture, and a policy able to widen it would be a policy able to reintroduce the defect. `debug_dump.MIN_ENV_CREDENTIAL_LENGTH` is a correctness floor, not a tuning knob: `redact_text` replaces by substring, so accepting a one-character environment value as a credential would rewrite every occurrence of that character and destroy the history it exists to preserve. `tool_dispatch.DEFAULT_HYPOTHESIS_CONFIDENCE` is the neutral midpoint used when a model omits confidence from a `hypothesis_register` call -- a defined value for a missing field, where any other number would assert a belief the model did not express. `agent_prompts.TASK_LOG_PREVIEW_CHARS` bounds how much of a task string reaches a log line; it trades log volume against correlatability and touches no governed behaviour. Eight further discovered names are recorded as `EXCLUDED` rather than triaged because they are facts, not limits: the hex-width constants in `publish_policy_artifact` and `shadow_planner` (`POLICY_VERSION_HEX_LEN`, `SHA256_HEX_LEN`, `TASK_ID_HEX_LEN` -- SHA-256 is 64 hex characters whatever a policy says), `pretooluse_guard`'s `ALLOW_EXIT`/`BLOCK_EXIT` (defined by the Claude Code hook protocol, not by this repository), and `langgraph`'s `EXPECTED_NODE_COUNT`/`CHANNEL_COUNT` (structural facts about the compiled graph and the state schema that their own tests pin)
