# DEC-056: Per-stack governance mirroring collapses to a root `.governance/` plus `--workspace` on shared gates

## Context

Per-stack governance mirroring collapsed to root `.governance/` (NS-31 / R-SR-5 / R-SR-29; Memo 4; audit M23 / H12), superseding DEC-005's push-posture mechanism and DEC-029 (2).

node and jvm each carry ~14 shim scripts, near-byte-identical `policy.json` / `agent-policy.json`, and near-identical personas; root `make validate` already runs shared governance from inside `harness/node`; `check_dedup.py` exists to police a layout that created the copies (M23). DEC-013 previously rejected moving `.governance/` to repo root citing DEC-005. Options for layout: keep dual trees -- rejected (accidental complexity every PR pays); collapse after jvm/langgraph/openspec decisions -- chosen (Memo 4; R-SR-29)

Migration order: Phase E step 15, last of the four deletions (jvm → langgraph → openspec → mirroring)

R-SR-5 / AC-5; R-SR-29 / AC-29 (`harness/node/scripts` only `run_vitest.sh`; no `check_dedup.py`; `python -m harness.shared.validate_policy --workspace harness/node`; root `make validate`; tests exercise root `.governance/`). INV-3 decided here. Evidence: plan review-record "Four in-or-out memos"; audit M23

## Decision

one root `.governance/`; `--workspace` on the seven CWD-relative gates; `[project.scripts]` entry points replace the 28 shim scripts (keep `harness/node/scripts/run_vitest.sh`); delete `check_dedup.py`; five PRs per Memo 4, `[project.scripts]` first, each green alone (AC-29). Supersedes DEC-029 (2): the 31 `sys.path` bootstrap / per-stack runpy sites are removed by the entrypoint migration rather than accepted-as-is. **Push posture (plan open question 2; supersedes DEC-005's mechanism, preserves its agent-push property -- Option A):** create root `.governance/allowed-remotes.txt` so `validate_adoption` and the pre-push hook have a real allowlist; replace DEC-005's absence-as-control with an **explicit PreToolUse / agent-policy denial of agent-initiated `git push`**, independent of allowlist presence. Human `git push` continues to be checked by `pre_push_scan.sh` against the root allowlist. (Alternative Option B, not chosen: allow agent pushes to allowlisted remotes and rely on pre-push alone -- would drop DEC-005's accepted consequence.) `.governance/**` ceases to be a declared-dormant protected_paths pattern once the root directory is live; the pattern arms on the files this DEC creates
