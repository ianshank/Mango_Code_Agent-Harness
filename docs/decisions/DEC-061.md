# DEC-061: Windows-platform skips for GNU Make-dependent and POSIX-shell stub tests approved

## Context

Several governance proofs invoke real GNU Make via `subprocess` or use
`#!/bin/sh` stub binaries. Windows developer machines typically lack GNU Make
and a POSIX shell. Originally logged as DEC-058 on the feature branch;
renumbered to DEC-061 on merge so DEC-058 remains the hypothesis-surfacing
record.

## Decision

(1) `test_check_secret_allowlist.py::TestScanFindings` uses `#!/bin/sh` stub
binaries that cannot run on Windows; the real gitleaks scan runs on Linux CI
via `make secrets-allowlist-check`; all other tests in that module run on every
platform.

(2) `test_verdict_forgery_regression.py` classes that invoke real GNU Make,
`test_gate_truthfulness_e2e.py`, and selected `test_makefile_contracts.py`
cases skip when `shutil.which("make")` is absent; all run on Linux CI where
Make is always present.

## Consequences

Matches the accepted-consequence shape of DEC-026's POSIX-only cases: local
Windows skips are waived and named; Linux CI remains the fail-closed proof.
