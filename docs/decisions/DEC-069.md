# DEC-069: INV-13 isolation backend is Landlock; MIN_ABI_FOR_NET is a UAPI floor, not a policy budget

## Context

AEI step 6 printed host inventory on every `make validate` leg. Step 7 must
choose a primitive that can enforce **both** filesystem confinement to
`ExecutionRequest.workspace` and outbound-network deny on the runners that
prove it (R-AEI-13), or close under C-AEI-6. A vendor choice written from this
Cloud Agent host alone would repeat AEI problem-statement item 5.

GitHub Actions `ubuntu-latest` (PR #128 head `c2c19ee`, CI run 34298491054,
`build (3.10)` / `build (3.12)` / `build (3.14)`, 2026-09-09):

```json
{
  "container_runtimes": {"reachable": ["docker"], "state": "enforced"},
  "landlock_abi": {"abi": 7, "state": "enforced"},
  "lsm": {
    "names": ["lockdown", "capability", "landlock", "yama", "apparmor", "ima", "evm"],
    "state": "enforced"
  },
  "schema_version": 1,
  "unprivileged_userns": {
    "state": "enforced",
    "sysctls": {
      "apparmor_restrict_unprivileged_userns": "1",
      "max_user_namespaces": "63838",
      "unprivileged_userns_clone": "1"
    }
  }
}
```

This agent VM (kernel `6.12.94+` x86_64, **not** GHA): Landlock ABI 6,
LSM `capability,landlock,selinux`, no reachable container runtime, and
`max_user_namespaces` present without the clone/apparmor sysctl files.

Landlock ABI 4 is the UAPI revision that added `LANDLOCK_ACCESS_NET_BIND_TCP`
and `LANDLOCK_ACCESS_NET_CONNECT_TCP`. Below that, filesystem `PATH_BENEATH`
cannot attest `network_isolation=enforced`. Anthropic sandbox-proxy
environment variables cannot attest it either (R-AEI-15). Unprivileged
`user+net+mount` needs a user namespace; GHA sets
`apparmor_restrict_unprivileged_userns=1`. Docker is reachable on GHA and is
not the first primitive for this CI. C-AEI-6 is therefore not the outcome:
Landlock ABI 7 (GHA) and ABI 6 (agent VM) both meet the floor, and a child
`PATH_BENEATH` + default-deny TCP ruleset was measured to block an outside
read, an outside write, and a loopback `CONNECT_TCP` on this VM.

`landlock_backend.MIN_ABI_FOR_NET` is that UAPI floor. Putting it in
`governance-policy.json` would invite operators to lower the ABI until
`network_isolation=enforced` became a lie. System read-execute paths
(`landlock_restrict.SYSTEM_RO_PATHS`: `/usr`, `/lib`, `/lib64`, `/bin`,
`/sbin`, `/proc`, `/dev`, plus runtime `sys.prefix` and the interpreter
parent) are the same class of constant: they exist so the confined child can
still run `bash` and the interpreter. They are not a policy allowlist, and
`/etc` is deliberately absent so `/etc/passwd` is not inherited.

## Decision

The INV-13 isolation backend is Linux Landlock, implemented by
`harness.shared.governance.landlock_backend` (`LandlockBackend`) applying
rules via `harness.shared.governance.landlock_restrict.apply_landlock` in the
child `preexec_fn`. `landlock_backend.MIN_ABI_FOR_NET` is 4. A host whose
probe reports Landlock `absent`, `undetermined`, or an ABI below that floor
is unavailable; `execute` returns `BLOCKED` and never falls through to
`ProcessBackend` (C-AEI-3).

Policy is compiled in memory from `governance-policy.json` and
`agent-policy.json` at backend start (`sandbox_policy.compile_sandbox_policy`);
no derived artifact is committed (R-AEI-14).

The broker **default remains `ProcessBackend()`**. Tests construct
`LandlockBackend` directly. Switching the default is a later DEC; this one
does not add `isolation.backend` inside the `execution` block and does not
invent a third `execution.routing` value (DEC-043 / AC-11).

`network_isolation=enforced` means Landlock default-denied TCP bind/connect.
UDP and ICMP are residuals and do not get to mint that field. Process
isolation stays `unenforced`. A sandbox digest is recorded only when the
backend name is `landlock` and both filesystem and network fields are
`enforced`; `ProcessBackend` cannot claim INV-13 complete.

## Consequences

- AC-13, AC-14, AC-15, and AC-16 can go green against `LandlockBackend`
  without waiting on Firecracker, gVisor, or OpenShell-in-Actions.
- C-AEI-6 stays on the spec as the close if a future runner loses Landlock;
  it is not the close of this measurement.
- HMAC → DSSE/Sigstore remains deferred until a sandbox digest exists on a
  path someone actually runs. The default broker path still has four of five.
- Changing the ABI floor or the system RO path tuple requires a superseding
  decision, not a policy edit.
