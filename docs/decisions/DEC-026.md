# DEC-026: Python skip accounting: `conftest.py` writes every pytest skip to a TSV that `make verify-zero-skips

## Context

Recorded as a governance decision on the historical pipe log.

## Decision

Python skip accounting (INV-2 parity; tech-debt-hardening-plan R-TDH-19). Node proved "no unapproved skip" from Vitest's JSON; Python had nothing, and 36 langgraph cases plus four empty-parametrize skips ran unaccounted on every CI leg. Now: harness/shared/tests/conftest.py records every skip (`unique_id\tdisplay\treason`, via `_skip_events.py`) to a TSV that `make verify-zero-skips-python` -- in `ci` and `ci-python` -- feeds to the existing `verify_zero_skips.py --junit-events` gate, so no new format and no new dependency. The four empty-parametrize sites (`test_ci_gate_coverage.py`, `test_import_purity.py` x2, `test_test_quality.py`) became loops: an empty waiver registry is the healthy state and must not read as a skip. The gate gains an optional `unique_id_glob` for JUnit-framework waivers, matched with fnmatch against the whole nodeid, because the langgraph condition covers ~40 parametrised nodeids across three files and one row per nodeid would be a registry nobody maintains; a glob waiver still requires the decision id inside the skip reason, so a new skip under a waived path without `(DEC-026)` in its reason is unapproved. Waivers live in harness/shared/tests/skip-waivers.json rather than a root `.governance/` (kept dormant by DEC-005; plan open question 6 resolved this way). Waived conditions: NVIDIA_API_KEY absent (live suites), langgraph absent (a local run only; CI deselects on 3.9 and installs elsewhere), non-POSIX platform (bash hooks, chmod/symlink cases), mcp absent (3.9 only). Left unwaived on purpose: `test_makefile_contracts` (ci-python missing), `test_lint_config_liveness` (no per-file-ignores), `test_invariant_liveness` (dormant invariant) and `test_import_purity` (declared side effects) -- each fires only when a registry that should be empty is not, which is a signal to investigate, not to waive
