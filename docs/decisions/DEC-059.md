# DEC-059: Windows-platform skip for AF_UNIX egress-floor proof approved

## Context

`test_egress_floor.py::test_a_unix_socketpair_is_permitted_while_tcp_still_raises`
proves the AF_UNIX socketpair is permitted while TCP is refused. The proof
requires `socket.AF_UNIX`, which is absent on Windows Python builds where the
optional AF_UNIX Windows feature is not installed.

Originally logged on the feature branch as DEC-057; renumbered to DEC-059 on
merge with `origin/main` so DEC-057 remains the hypothesis-revision record.

## Decision

Skip the AF_UNIX socketpair half of the dual-assertion proof on Windows when
`socket.AF_UNIX` is absent. The TCP block
(`test_the_socket_guard_is_actually_active`) continues to run on every
platform. The proof runs unconditionally on Linux CI where AF_UNIX is always
present.

## Consequences

The socketpair proof is not exercised locally on Windows developer machines
without the optional feature. Egress TCP refusal remains enforced everywhere.
