# DEC-010: A command's action is derived from the command and fails closed to an action no role holds

## Context

Recorded as a governance decision on the historical pipe log.

## Decision

The action a command exercises is derived from the command, never supplied by the caller: a constant action grades pytest and `rm -rf /` identically and human_approval_required_for is then never reached. Classification is an allowlist whose default, for anything unmodelled, is an action no role holds, so an unrecognised command denies for every agent deterministically. ExecutionBroker gains a process backend that pins the working directory, bounds runtime and caps captured output -- containment, explicitly not isolation: it confines neither the filesystem nor the network, so INV-13's sandbox digest remains unsatisfiable and no result claims otherwise. Isolation is deferred to a capability profile because the primitive cannot be exercised on this repository's CI runners, and a gate that cannot run is the defect this programme exists to close
