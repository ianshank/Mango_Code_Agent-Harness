# DEC-030: The Python skip-evidence hooks (DEC-026) and the langgraph deselection live in the repository-root `

## Context

Recorded as a governance decision on the historical pipe log.

## Decision

Session-wide pytest hooks belong at the rootdir. DEC-026 put the Python skip-evidence hooks (`pytest_runtest_logreport` collecting every skip, `pytest_sessionfinish` writing the TSV that `make verify-zero-skips-python` reads) and the R-TDH-4 langgraph deselection in `harness/shared/tests/conftest.py`. pytest scopes a conftest's per-item hooks to the directory that conftest sits in, so a skip under `harness/api_server/tests` produced no evidence row and the Python half of INV-2 silently covered only one of the two suites `make coverage-python` runs. Found by a probe while colocating `harness/control-plane/tests/` (tech-debt-hardening-plan R-TDH-26): two skipping tests in two sibling directories, zero rows written. The hooks now live in a repository-root `conftest.py` that delegates to `harness/shared/tests/_session_hooks.py` (a plain module, unit-testable); the shared conftest keeps re-exporting `LANGGRAPH_DESELECT_ENV`/`LANGGRAPH_MARKER` for the tests that pin the wiring, and registers no session hook, because a second registration would record every shared-suite skip twice. `test_session_hooks.py` proves the fix the way the gap was found: a `pytester` run of the real root conftest over two sibling suites yields both rows with rootdir-relative ids, and a placement test fails if any `harness/*/tests/conftest.py` defines one of the four hooks again. Considered and rejected: loading the hooks as a `-p` plugin from `addopts` (depends on cwd being importable before `pythonpath` applies, so a bare `pytest` would differ from `python -m pytest`) and re-importing the hook functions into each directory conftest (double registration). The waiver registry needed no change: the api_server suites currently produce no skips, so nothing was hidden, only unguarded
