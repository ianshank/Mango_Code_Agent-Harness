# DEC-009: The policy decision point runs in process

## Context

Recorded as a governance decision on the historical pipe log.

## Decision

The policy decision point is evaluated in process rather than as a host subprocess. ExecutionBroker ran harness/control-plane/tool_broker_reference.py with sys.executable, on the host, before check_command -- from a path inside the agent's workspace, so replacing that file replaced every subsequent verdict; and the call was guarded by `if _PDP_PATH.exists() and _POLICY_PATH.exists()`, so a missing file skipped the verdict instead of denying. The decision is set membership; running it as a subprocess bought nothing and cost a code-execution primitive. tool_broker_reference.py is retained as the contract an external broker mirrors, and test_policy_decision.py pins that the two agree on every representative request
