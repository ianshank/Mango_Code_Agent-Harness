# DEC-033: The `pip` ecosystem is removed from `.github/dependabot.yml`, completing DEC-031 instead of restatin

## Context

Recorded as a governance decision on the historical pipe log.

## Decision

The `pip` ecosystem is removed from `.github/dependabot.yml`, completing DEC-031 rather than restating it. DEC-031 closed PRs #38-#46 as superseded by the universal `requirements-lock.txt` and named the weekly `lock-upgrade-check` job the Python upgrade signal from then on -- but left the ecosystem enabled, so the decision and the configuration disagreed in the only way that has an effect: twelve bot PRs reopened on 2026-09-02 (#62-#73), including a `mypy` 1.11 -> 2.3 major bump no lock-driven process requested. Against a locked dependency set a per-package pin is either a no-op or a reintroduction of the per-package pinning the lock supersedes, so the queue would have kept refilling with PRs the decision log says to close. The `npm` and `github-actions` ecosystems stay: neither is covered by the Python lock, and R-TDH-10 wants the action majors moving. The reopened pip PRs are left for the maintainer to close -- closing another account's PRs is not this change's to make -- and the reason is recorded here so the next audit does not read them as pending work. Re-enabling the ecosystem requires superseding DEC-031, not editing the config
