# DEC-005: The MAS orchestrator consults the PreToolUse guard in-process from the installed harness, never from

## Context

Recorded as a governance decision on the historical pipe log.

## Decision

The MAS orchestrator consults the PreToolUse guard in-process from the installed harness rather than resolving harness/shared/pretooluse_guard.py under workspace_dir: the workspace is agent-writable, so a guard loaded from it can be replaced by the model whose commands it checks, and the previous `if guard_script.exists()` made the guard optional. Guard unavailability now denies (INV-9)

## Consequences

agent-initiated `git push` is blocked, because the repository root carries no .governance/allowed-remotes.txt and remotes.py fails closed on the missing file; creating a root allowlist is rejected because `.governance/**` is a declared-dormant protected_paths pattern
