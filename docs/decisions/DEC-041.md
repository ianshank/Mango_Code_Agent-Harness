# DEC-041: `test_verify_zero_skips.py` (684/700 lines) splits at its own section banner: the `unique_id_glob` c

## Context

Recorded as a governance decision on the historical pipe log.

## Decision

`test_verify_zero_skips.py` is split, and the per-file size budget reports headroom instead of only breaches. The module stood at 684 lines against a 700-line `limits.test_size_budget_lines` -- sixteen lines from a red gate, in the suite for INV-2, the invariant most likely to gain a test, since every new waiver shape lands there. The `unique_id_glob` cases move to `test_verify_zero_skips_glob_waivers.py`, cut at the section banner that module had already drawn around them. The trigger was mechanical but the seam is not, and DEC-035's rule applies: split where the defects fall, not at the line count. A glob waiver widens *which node ids a waiver addresses* while leaving *what it approves* untouched, and that distinction is exactly what DEC-026 and the later waiver narrowing both turned on; every case in the new module is about the address. `run_script` and the `test_files` fixture move to `harness/shared/tests/_zero_skip_harness.py` and are imported by both halves rather than copied -- a duplicated runner is how the two would come to disagree about what "run the gate" means, which is the divergence `check_dedup.py` exists to prevent one layer down. The fixture is imported by name rather than placed in the directory `conftest.py` deliberately: a conftest fixture is visible to every module in `harness/shared/tests/`, `test_files` is a generic enough name to shadow something later, and DEC-030 already records what conftest-scoping errors cost here. The set of test functions is unchanged -- verified by diffing the sorted `def test_` names before and after, whose only difference is the fixture that moved. Separately, `test_junit_missing_fields` is renamed to `test_a_junit_waiver_missing_its_address_is_rejected_before_any_evidence_is_read`: it read as a test about JUnit evidence while passing `--vitest-json` with no JUnit events involved at all, its actual subject being a waiver that declares `framework: junit` without the fields naming which node id it addresses. Finally, `_check_line_budget` now logs the closest file and its remaining headroom on a passing run. The budget was a cliff -- silent until it failed -- so the first signal a contributor got was a red gate mid-PR, and nothing surfaced the 684/700 approach; this session found it only by going to look. The line is INFO, cannot change the verdict, and reports the measurement the check already performs rather than introducing a second threshold that would have to be kept in step with the first. It is suppressed on a failing run so the failure leads rather than competing with a gauge for the runners-up. Both behaviours carry tests, and removing the headroom line fails one of them. Cost stated rather than hidden: editing `validate_invariants.py` adds a fifteenth row to this PR's attestation table for what is a convenience, not a correctness fix; it is taken because the gap it closes had just produced a near-miss in this same session
